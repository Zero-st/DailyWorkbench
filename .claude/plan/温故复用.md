# 实施计划 · 今日「温故」卡（蒸馏复用抓手）

> 设计见 `docs/温故复用-设计.md`。前端-only walking skeleton，零后端、零依赖。

## 步骤

1. **新建 `js/features/recall.js`**
   - `import { esc, jsStr } from "../core/util.js"; import { icon } from "../core/icons.js";`
   - 常量 `INTERVAL=[0,2,7,16,35]`、`LS_KEY="wb_recall"`、`MAX=3`、`MODULE="蒸馏库"`。
   - `_state()`/`_save(map)`：读写 localStorage（try/catch，坏了当空）。
   - `_dueDays(rec, now)`：算超期天数（新卡=大值优先）。
   - `renderRecall()`：`fetch /api/kb/deposits?module=蒸馏库` → 交叉 state 挑未归档且到期的前 3（超期降序）→ `_draw()`；异常/空→ `#recallBlock` 清空（静默）。
   - `_draw(cards)`：`.card` 外壳 + 标题 `icon("history")+" 该复用了 · N"`；每卡仿 `.distill-card`：标题 + 平台 `icon()`+主题+“X 天没看” + `[打开][👍有用][✓已内化]`（`jsStr(vaultPath)` 传参）。
   - `recallOpen(vp)`：`window.switchView('distill'); window.distillOpen(vp);` + 记 lastReviewed。
   - `recallUseful(vp)`：box+1、lastReviewed=today → 保存 → renderRecall()。
   - `recallArchive(vp)`：archived=true → 保存 → renderRecall()。
   - 文件末尾挂 `window.renderRecall/recallOpen/recallUseful/recallArchive`。
   - 新增图标 `history`（回旋箭头）到 `js/core/icons.js`。

2. **`index.html`**：`#view-home` 内、`<div class="grid">` 前插 `<div id="recallBlock"></div>`。

3. **`js/app.js`**：`import { renderRecall } from "./features/recall.js";`；`render()` 里在 `renderTodayReview(d)` 后加 `renderRecall();`（try 内，已被 render 的 try/catch 兜）。

4. **`css/styles.css`**：加 `.recall-*` 小段（复用 token/`.distill-card` 风格）：容器间距、标题行、卡行、按钮条；明暗都走 token。

5. **缓存戳**：`bump_version.py` ASSETS += `js/features/recall.js`；`sw.js` FILES += `./js/features/recall.js`；跑 `python bump_version.py`。
