# 蒸馏库界面优化 + 界面设计准则

## Context

用户看到「蒸馏库」视图截图，觉得「UI 太差、排版有问题、没设计」，要求：① 从 GitHub/其它平台找现成 UI 设计 skill/MCP 来优化；② 优化后编写界面设计准则/风格，结合现有工作台。

**调研 + 根因已查清（只读）**：
- **不是设计缺失**。工作台早有一套成熟设计系统 —— `css/styles.css` 头部自称「设计系统 v7 · 活力糖果 · 圆润友好 · 科技基底」：完整 token（钢蓝 `--accent:#2b7fe0` + 糖果点缀色 + 4pt 间距 + 999px 胶囊 + 16px 卡片 + 明暗双主题 via `body.light`）、完整组件库（`.button/.chip/.card/.sf/.kb-layout` 等）。
- **蒸馏库丑的真因**：`js/views/distill.js` 用了 **10 个从没写过 CSS 的类**——`distill-filter / distill-card / dc-title / dc-meta / dc-head / dc-chip / distill-form / df-row / df-step / df-actions`；外加 `.chip.on`（选中态）全局未定义、`#dfBody` textarea 没挂任何类。外层 `.kb-*` 框架是跟知识库视图共享的、已有样式，所以「两栏骨架在、里面全裸奔」——这正是截图症状（表单行错位、textarea 重叠、卡片无样式）。
- **豆腐块 ☒**：本机 Linux 缺 emoji 字体，`.si` emoji 全渲染成方框。工作台其实**已在迁移到内联 SVG**——仪表盘卡头、顶栏「同步/主题」按钮已用 `.ic-svg`（Feather/Lucide 描边风：`viewBox="0 0 24 24" stroke="currentColor"`）。只是侧边栏 13 个 `.si` 和蒸馏视图图标还没迁。

**用户决策（已确认）**：① 路线＝**额外装外部设计 skill**（不是我推荐的"纯沿用"）；② 图标＝**关键图标换内联 SVG**。

**目标产出**：把外部设计 skill 的方法论引进来当"设计透镜"，用它审视并补齐蒸馏库缺失样式 + 把关键图标迁到内联 SVG，最后写一份《界面设计准则》codify 现有 v7 体系 + 该 skill 的准则 + "新视图检查清单"（防止再犯"新类没写 CSS"）。守住零依赖·离线可跑北极星。

### C. 编写《界面设计准则》→ `docs/design/界面设计准则.md`（活文档）

codify 现有 v7 + frontend-design skill 准则，落成可执行规范。大纲：
1. **北极星与来源**：零依赖·离线；引入 `anthropic/frontend-design` 当审查透镜；风格血脉（footer 已注：参考 xfc-obsidian-workbench-builder-community，已重皮为"活力糖果圆润科技风"）。
