# 0001 以「零构建 · 零依赖 · 离线可跑」为北极星

> ⚠️ **已被 [0010](0010-relax-zero-dependency-north-star.md) 修订**：现行北极星是
> 「零构建 · 依赖极简且可撤回 · 本地起服务即可跑（离线优先）」。下方为原始决策记录，保留不改。

- 背景：个人单人维护的工具，需在选型时有一条能定盘的元规则。
- 决策：把「零构建 · 零依赖 · 离线可跑」定为项目北极星，一切"要不要引入 X"先过它。
- 理由：单人工具最大失败模式不是功能不够，而是三年后工具链腐烂跑不起来；`git clone` 即跑是最宝贵的资产。
- 代价：放弃了框架/构建带来的部分开发便利；何时重估——引入了构建步骤或出现第二人长期维护时。
