这版效果图敲定了什么（确认后照此实施）

  • 形态：右侧全局浮遊 AI 副驾 dock，非模态、跨视图常驻；取代「讲讲跳转到整页」。
  • 能力：讲讲喂卡片开讲 → 可继续追问（多轮对话）；也能空手直接聊；顶部「提炼要点/存库」同样喂它。
  • 缩放：右钉 + 拖左缘调宽 + 拖下缘/角调高 + localStorage 记忆尺寸与开合。
  • 复用：整套 AI 聊天引擎照用（aiMsgs/wb_ai_history/agentStream 流式）；dock 作唯一挂载点，导航「AI 助手」改开合 dock，历史不分叉。
  • 深挖 / 写闸：讲讲先 WebFetch 原文；落库一律「起草 → 人点保存」经 /api/kb/save，AI 不自动写。
  • 边界：新 js/features/convo-dock.js + 接线 + 一批 CSS；零后端改动、不碰 data.json//api 契约、零新依赖 → 双向门，不写 ADR。
