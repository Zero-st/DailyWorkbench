01一次判断，东西怎么流动

只有三样东西：材料、题目、答案。最关键的一点是最右边那一格——答案不等于许可，去不去执行永远是你自己的代码说了算。

它什么都不记得：看不见你的聊天记录、文件或上一次提问。每份作业必须自带全部材料（context-and-throughput.md）。它也只认文字，截图得先转成字（api.md）。

装进来的是五个文件夹，但它们不是五个独立工具。原文的说法是：这些是模式（modes），不是额外安装的东西。

jev/总纲

怎么出题、怎么配置、怎么跑。另外四个都从这里延伸，共用同一个脚本和同一套作业格式。

jev-triage/考法① 分类

一堆工单/邮件挨个判归属和优先级。批量前必须先跑小样对一致性。

jev-documents/考法② 找证据

在文档里指出「哪一段才是答案」，或判断某句话有没有出处支持。

jev-eval/考法③ 评判

看已经做好的东西合不合格，比如一次改动是不是靠削弱测试骗过 CI。

jev-act/考法④ 选下一步

在浏览器或游戏里，从「当前能点的东西」里挑一个。挑中不等于可以点。

03两条路：先走不花钱的那条

原文要求这个选择由你明确做出——agent 不许替你选，报错也不构成偷偷换路的理由。

模拟B · 先走这条

  • 不花钱，不需要任何账号或密钥
  • 材料不外发
  • 让手边现成的 AI 按同一套规矩答题
  • 不给把握程度——必须留空，不许编
  • 用来先把题目调顺：选项够不够、兜底留没留

真调 JevA · 调顺了再来

  • 要 OPENROUTER_API_KEY 或 TYPESAFE_API_KEY
  • 真扣钱，材料发到外部服务
  • 输入 $0.042 / 百万 token，输出免费（2026-09-22 读到，原文注明会变）
  • 一次材料上限 32,000 token
  • 给概率和 confidence，可以据此设阈值

04三个最容易踩空的地方

「检查通过」不等于「拿到答案」

加了 --dry-run 跑完，它会把你的作业原样打印回来——里面一个答案都没有。那一步只是在看你作业的格式合不合规矩，根本没去判断。

jev/scripts/jev.py · "Validate and print request; no API call"
它选中了，不等于你被允许去做

Jev 说「该点这个删除按钮」，那只是它的看法。真去不去点，必须由你的代码、权限检查和人工确认决定。脚本输出里有个字段 executes_actions，值被硬编码成 false。

jev/scripts/jev.py · build_report()：「NOT permission to perform an action」
把握高，不等于答对了

本仓原文自带的实测数字：160 道题里，把握 ≥ 0.9 的有 100 道，这 100 道错了 8 道；只看高把握的因果判断，20 道只对 14 道。另外「反复问都答得一样」只说明它稳定，不说明它对。

jev/references/calibration.md · 「Repeated agreement is consistency, not calibration」

05什么时候不该用它

写文章写代码 → 用普通大模型。算数、数数、比日期、对账 → 写代码，别让它判。当成事实来源 → 它只判断你给的材料，不会去查证。看图 → 它只认文字。只有一两条要判断 → 出题加调试比手工还费事。中文材料 → 原文写明英文支持最好，中文负载要你自己另测一轮。

还有最根本的一条：它的价值完全来自重复次数。判 5 次，手工更快；判 5000 次，它才开始划算。
