第 2 问

一句话说它是什么

Hypit 是一套让 AI 助手「尝一口别人的菜、反推出菜谱、再照菜谱做出一堆新菜」的厨房系统。菜是视频，菜谱是可以改、可以重做的工作流。

你特别想搞清的 ①：「克隆一条爆款」到底克隆的是什么？

不是复制视频文件。README 原话：「丢一条视频进来，拿到整份 workflow —— 画面、字幕、B-roll、特效。不是拆解脚本」；「拿到的都是可编辑、可重跑的工作流，而不是一次性的成片」。用厨房话说：成片是端上桌的那盘菜，吃完就没了；工作流是菜谱加备料单，能反复做、能换料。Hypit 给你的是后者。

B-roll：口播画面之外插进来的配图、配镜头，比如说到「兰博基尼」时闪一张车的图。workflow / 工作流：一套写在文件里、能重跑的制作步骤。

  • 软件的「用户」是 AI 助手（README 点名 Claude Code、Codex），你只跟 AI 助手说话；Hypit 给助手一套「视频的语言和系统」。
  • Coding Agent / AI 编程助手：能在你电脑上读写文件、执行命令的 AI 程序，比如 Claude Code、Codex。它不是 Hypit 的一部分，要单独装、单独付费（见第 8 问）。

第 3 问

第一性原理：它到底改变了什么

  • 为什么以前做不到：以前视频里的画面得实拍、字幕得人听着对、改动得人手动挪。现在这三件事各有一个成熟的工具接手（见三根柱子），Hypit 做的是把它们串成一套「文件 → 成片」的流水线。我的解读
  • WhisperX：一个开源语音识别工具，能把一段话里每个词开始、结束的时刻标出来。README 每个示例都写「WhisperX 负责逐词对齐」。
  • 生成模型：能按文字描述生成图片、视频、声音的 AI。README 示例用到 Seedance（生视频）、GPT Image（生图）、Fish Audio（生声音）。这些都不是 Hypit 自己的，是外部服务，要花钱（第 8 问）。
你特别想搞清的 ②：「锚定在词上，不是秒上」是什么意思？

厨房里的比喻：菜谱写「等水开了再下面」，而不是「第 3 分 12 秒下面」。火大火小、锅大锅小，「水开了」这个时刻都对；写死「第 3 分 12 秒」，换个锅就煮糊了。

Hypit 把字幕、特效、配图挂在「说到哪个词」上，而不是「第几秒」上。你改了一句台词、换了个说话快慢不同的主播，它重新听一遍词在哪一刻，所有东西自动跟着挪。README 原话：「改一句台词，时间轴自己重排」。为什么重要：这是「一份工作流出 100 个变体」能成立的前提——按秒挂的东西每改一次都得人工重对，按词挂的不用。

最反直觉的一个设计决定

这套软件的头号用户是 AI，不是人。README 第一句就是「为 AI Agent 提供一套制作视频的语言和系统」；它的技能说明书（SKILL.md）开头对 AI 说「你是被委托的导演和制片人」。它没有给人手工拖拽做视频的主界面——Studio 只用来看和微调，真正的生成和渲染都靠命令 hypit build。

为什么这样定（我的推断）：写「视频配方文件」这件事又细又多，AI 写得比人快得多；人只负责三件事——给参考、说想改什么、看报价点头。文档里确实把「确认费用、开始制作」单独列为一步。我的解读

第 4 问

原理：我给它什么、它做了什么、吐出什么、给谁用

你特别想搞清的 ③：「视频还能写代码」是怎么回事？SVML 和「编译器」是什么？

SVML 是 Hypit 自己定的一种「菜谱书写格式」：哪句台词、配什么画面、字幕长什么样、说到哪个词弹什么特效，全写在一个文本文件里（后缀 .svml）。编译器就是那个「读菜谱、自动下厨」的机器人厨师：把这份文本变成真正的 mp4。README 的说法是「不调用生成模型也能编译成一条成片」。

拿你熟悉的东西类比：这和「文字版菜谱 → 照着做出菜」是一回事，只不过做菜的是程序。好处也一样：菜谱是文字，改一个字很容易；菜做坏了，不用重新买菜，改菜谱重做就行。

真实的「视频代码」长这样（这是「本次做什么」的 .svrun 文件开头，照抄文档）：

<?svml using="@hypit/run-markup@1"?>

<svrun version="1">
  <author source="./main.svml"/>

意思是：「这次按 main.svml 这份菜谱来做。」你不需要会写它——AI 助手写；你只要知道它是一份能改、能重跑的文本文件。

  • 吐出什么：一条 mp4 成片，加上一个普通文件夹里的项目（菜谱文件 + 生成过的素材 + 每次执行的记录 Build Result）。文档说「项目保存在普通文件里，可以继续编辑」。
  • 结果给谁用：给你。可以在浏览器里打开 Studio（Hypit 自带的看片页面）逐帧看、微调字幕位置；也能在 Comments 页按时间点留意见，AI 助手会读取 FEEDBACK.json 里的意见去改。
  • Build Result：每跑一次 build 留下的「这次做了什么、产出了哪些文件」的记录；下次改菜谱重做，没变的素材直接复用，不重新生成（省钱）。

第 9 问

优缺点对照，以及它和剪映是什么关系

优点

  • 拿到的是可改、可重跑的工作流，不是一次性成片（README 原话）
  • 字幕、特效按词挂，改台词不用重对时间
  • 软件免费、不加水印、不按渲染次数收费（README）
