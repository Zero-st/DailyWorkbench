## 0 · 北极星（元规则，不是口号）

**零构建 · 零依赖 · 离线可跑** —— `git clone` 就能跑、双击 `index.html` 能看、三年后工具链不腐烂。

这是本项目最宝贵的资产：单人维护，最大的失败模式不是"功能不够"，而是"某天跑不起来"。**遇到"要不要引入 X"，先问它是否违背北极星——这一条能解掉 80% 的选型纠结。**

## 维度一 · 技术选型第一原则

### 「要不要引入 X」四问（按序问，任一为否即停）
1. **现在真需要吗？**（YAGNI——"以后可能要"是过度设计最常见的借口）
2. **违背北极星吗？**（引入构建/重依赖/必须联网 → 否）
3. **是单向门吗？**（不可逆决策 → 放慢、写 ADR；见下）
4. **是双向门？** 那就**直接试**，错了随时改，别开会纠结。

### 选型定论表（每格都带"何时该重估"，因为多数是双向门）
| 层 | 定论 | 何时重估 |
|---|---|---|
| 前端语言 | 原生 JS + **ES Modules**，不上 React/Vue、不引构建 | 引入了构建步骤 / 出现第二人长期维护 |
| 类型 | **JSDoc + checkJs**，只标模块边界 | 同上（那时全量 TS 的收益才够本） |
| 后端 | Python **stdlib http.server + 路由表**（`server.py` 的 `GET_ROUTES`/`POST_ROUTES`） | 端点激增 / 需请求校验 / 要 OpenAPI → FastAPI |
| 数据 | **JSON 文件当库**（`data.json`）+ Supabase 只管需云端共享的模型配置 | 出现并发写 / 多人 / 事务 → 才上 DB |
| 多端 | **PC-first**：桌面 PWA 为主体；原生/APK（Flutter/TWA）与 `lite/` 分叉均已下线（ADR 0005 及修订）；不并行多套 UI（一人维护两套最贵） | 桌面飞轮成型且有真实移动高频诉求时再评估 |

### 单向门清单（不可逆，必写 ADR 再动）
主数据库选型 · 对外 API / `data.json` 契约 · 交付形态 · 消息/存储格式。

## 维度二 · 模块与边界红线

- **ES Modules 从第一天起**。判据：**一个文件能不能一句话说清它干嘛**——说不清就是太胖，该拆。
  - 反例存档：重构前 `app.js` 2139 行单 IIFE、89 个 render 混在一个作用域。
- **`window.*` 桥接集中在"一处总机"**，不散落全项目。经典脚本（`schedule.js`/`kb.js`/`model-manager.js`）与内联 `onclick=` 靠它接线；`js/core/util.js` 挂公共工具、各模块只在文件末尾挂自己的处理器。
- **render 层只吃数据契约，禁读 DOM 判路由。**
  - 真实事故 `856df28`：渲染逻辑耦合到已删的 `.tab` 按钮 → 资讯页白屏。路由状态只认 `state.js`，不认 DOM。
- **状态单一真源 = `js/core/state.js`**；镜像到 `window` 只走**唯一写入方**（`setData`/`setView`）。**禁多处私有副本。**
  - 真实潜伏 bug：`__data/__view` 曾是 app.js 私有闭包、从未镜像，导致 `model-manager.js`/`kb.js` 的 `window.__data/__view` 守卫长期空转。现由 `state.js` 统一镜像修复。
- 反例存档：`view`/`tabpane` 双 DOM 体系（历史遗留，已统一为一套 `.view`）。

## 维度三 · 工程护栏 + 可移植

- **缓存戳自动化**：`bump_version.py` 按文件内容 hash 自动写 `index.html`/`sw.js` 的 `?v=` 与 CACHE 名。**禁人肉同步三处**——漏一处用户端就吃旧缓存白屏（这是 CI 硬门禁项：`bump_version.py --check`）。
- **设计准则是契约不是愿望**：`check_design_tokens.py` 校验 `css/styles.css` 令牌——**引用未定义变量（孤儿）直接红**；**化石令牌只许降不许升**（棘轮基线写在脚本常量，清一批就下调）。缘起：准则 v1.1 写「只用 `--space-*`」，实测裸 px 四百余处 vs 令牌几十处——**准则说的规矩必须有脚本查**，否则和任何文档一样漂移。CI 硬门禁项。新视觉 / 新组件先出 HTML 效果图过目再写代码（准则 §6.0）。
- **CI 必须真门禁**：`.github/workflows/ci.yml` 里 `bump --check` / `check_design_tokens` / flake8(E9,F7…) / pytest / `tsc --noEmit` 都是**真会变红**的。**禁 `|| true` 假绿**——宁可诚实删掉一个测试，也不留"看着在测其实没测"的绿灯。
- **单一契约**：`data.json` 是前后端唯一契约，类型定义只有一处——`js/core/net.js` 的 `@typedef WBData`。前端各视图（及来日的移动端）都消费它；后端 `export_data.py` 产出它。改契约 = 单向门。
- **类型化边界化**：checkJs 当前只覆盖 `state.js`/`net.js` 两个干净边界（`jsconfig.json`）。视图层是字符串拼接渲染，**不强求全覆盖**——硬追会淹没在 DOM cast 噪音里，是过度投入。日后按文件逐个加 `// @ts-check` 增量扩。
- **可移植**：环境绑定（路径 / 盘符 / 密钥 / 主机白名单）一律进配置——`wb_config.py` 按 **环境变量 > `workbench.local.json` > 平台默认** 三级读取（`workspace()`/`ollama_exe()`/`disks()`…）。**逻辑常量留代码**（如"日报保留 14 天"这类业务规则，进配置反而更难懂）。跨平台探测优雅降级，非 Windows 不抛异常。
  - 反例存档：曾硬编码 `E:\AITools\...`、`C:\Users\lenovo\...`，换机即废。判据一句话：**环境绑定 → 进配置；逻辑本身 → 留代码。**

## 维度四 · 人机协作流程（你 + 我怎么配合）

- **plan 先行**：复杂 / 不可逆任务先出 plan 再动手；trivial（改错字、单行）直接做，不为流程而流程。
- **小步提交**：一个 commit 一个主题、每步可独立回退；每步先**走查**（Chrome DevTools MCP 逐点视图 / 跑测试）+ 本地 CI 绿，再提交。
- **命令前中文说明副作用**：有写/删/网络/权限副作用的命令，执行前先用中文说清影响范围。
- **commit / push 只在你明确要求时**做，不擅自推送。
- **单向门才写 ADR**（3 行：决策 / 理由 / 代价），放 `docs/adr/`；双向门不写，直接试。
- **文档防漂移**：改了行为就顺手改 `README.md` / 本宪章。
  - 反面教材：`README.md` 一度还写"零后端、纯静态、双击 index.html 即可"，而项目早有 Python 后端——文档漂移会误导下一个人（包括未来的你和我）。

## 附 · ADR 轻量机制

**何为单向门**：见维度一清单。**只有单向门才值得写。**

模板（`docs/adr/NNNN-<kebab-title>.md`）：
```
# NNNN 决策标题
- 背景：一句话说清面临什么选择。
- 决策：选 X。
- 理由：因为……（对齐哪条北极星/原则）。
- 代价：放弃了……/ 何时该重估。
```
