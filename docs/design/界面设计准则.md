## 2 · 设计 token 速查（值以 `css/styles.css` 为准）

**明暗机制（重要）**：不是 `data-theme`、不是裸 `prefers-color-scheme`，而是 **`body.light` class 切换**。`:root` 是基色，`body.light{}` 覆盖。控制器在 `js/app.js`：三态 `localStorage["wb_theme"] = light | dark | system`，`applyTheme()` 加/去 `body.light`，并同步 `<meta name=theme-color>`。**默认 light**。
> 写新样式一律用 token 变量，别硬编码颜色——否则明暗切换时你的元素不跟着变。

| 组 | token（节选） | 用途 |
|---|---|---|
| 表面 | `--paper` 页底 / `--panel` 卡 / `--panel-2` `--panel-3` 更浅层 / `--input-bg` | 所有背景 |
| 描边 | `--line` 主 / `--line-soft` 轻 / `--line-mid` 中（虚线分隔用） | 每个面都有 1px 边 |
| 文字 | `--ink` 正文 / `--ink-strong` 标题 / `--sub` `--sub-2` 次要/说明 | 文字层级 |
| 主色 | `--accent:#2b7fe0` 钢蓝 / `--accent-strong` 深 / `--accent-2` 亮 / `--accent-ink:#fff` | **所有交互态** |
| 主色派生 | `--tint` `--tint-2`（浅底）/ `--accent-line` `--accent-line-2`（描边）/ `--ring` `--focus`（聚焦）/ `--sh-btn`（按钮影） | hover/选中/聚焦 |
| 糖果点缀 | `--candy-orange` 专注 · `--candy-purple` 复盘/标题 · `--candy-green` 完成 · `--candy-cyan` 今日 · `--candy-amber` 警告（各带 `-soft`/`-line`） | **只做语义与图标片，绝不大面积填充** |
| 语义 | `--green` `--amber` `--red`（各带 `-soft`/`-line`） | 成功/警告/危险 |
| 圆角 | `--radius-lg:16px` 卡 / `--radius:14px` / `--radius-sm:10px` / `--radius-pill:999px` 按钮·chip·badge | 全圆润 |
| 间距 | `--space-3xs:4 … 3xl:56`（**严格 4pt 栅格**）；卡间距常用 `--space-xs`(12)，卡内边距 `--space-md --space-lg`(20/24) | 一切 gap/padding |
| 字号 | `--text-xs:12 … 2xl:24`；正文 `--text-md`(15)/行高 1.6 | 字号阶 |
| 字体 | 正文 Inter→系统中文栈；数字/ID/路径用 `--mono` + `tabular-nums` | 排版 |
| 阴影/动效 | `--shadow-sm/md/lg`（柔软果冻感）；`--ease` `--ease-out`；`@keyframes fadeIn`（错峰入场） | 立体与过渡 |

## 4 · 图标策略（豆腐块 ☒ 教训 → 硬性红线）

**背景**：曾大量用 emoji 当图标（侧边栏、按钮、chip），在缺 emoji 字体的系统（如某些 Linux）**全渲染成豆腐块 ☒**，整个界面显得"没设计"。

**红线**：
1. **图标一律用内联 SVG（Feather/Lucide 描边风，`stroke="currentColor"`），不依赖 OS emoji 字体。** 统一走已有 `.ic-svg`（`css/styles.css` 已定尺寸/对齐）。
2. 静态图标（如侧边栏）直接在 `index.html` 内联 `<svg class="ic-svg" …>`；动态视图用 `js/core/icons.js` 的 `icon(name)` 助手拼 HTML 字符串。
3. **emoji 只能做纯装饰，绝不单独承载语义**——关键动作/导航必须带文字标签兜底（缺字体也认得出）。
4. SVG 规范：`viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"`。

**`icon()` 用法**（`js/core/icons.js`）：
```js
import { icon } from "../core/icons.js";
'<button class="button sm" onclick="foo()">' + icon("plus") + ' 新建</button>'
```
已收录：plus / copy / download / link / edit / tv / book / file / beaker。缺就往 `P` 里加一条 path。

> **两套 icon 助手（现状，勿再增第三套）**：`js/core/util.js` 的 `ic(name)`（Feather 集，更全，已 `WB.ic` 桥接 → 经典脚本 kb/model-manager 可用；ES 模块 `import { ic }`）与 `js/core/icons.js` 的 `icon(name)`（较小，仅 ES 导入，platforms.js/inbox/distill 在用）。两者同款描边风、同吃 `.ic-svg`。新代码优先 `ic()`（覆盖广 + 经典脚本能用）；缺图标往对应 `ICONS`/`P` 加一条 path。**日后宜合并为一套**（双向门，YAGNI 暂不动）。

**已迁移**：侧边栏 13 项、顶栏同步/主题按钮、仪表盘卡头、蒸馏库全部图标；**v0.9.1 批量收尾**——知识库树（📁/📄 ×333）、模型管理（供应商徽标/🧠/➕/👁）、AI 助手（🧠/📥/📘/⚠️）、今日「更多工具」（🎬/💡/🧹）、顶栏时钟 🕐、同步/自检按钮与状态栏（⏳/✅/⚠️/❌/🔍）全部 SVG 化。
**保留不改**：dingbat 类符号 `✓ ✕ ★ ☆ ✎`——各系统基础字体（含无 emoji 字体的 Linux）均可渲染，非豆腐区，转换代价 > 收益。**待增量迁移**（YAGNI）：`💾 ▶` 等零星装饰，碰到顺手换。

## 5 · 排版与布局节奏

- **间距**：只用 `--space-*`（4pt 栅格），别写裸像素。
- **边框**：每个面 `1px solid var(--line)`；hover/选中换 `--accent-line-2`/`--accent-line` + 微抬 `translateY(-1px)`。
- **层级**：页标题 `h1` 21/800（带渐变竖条前缀）；卡标题 `h2` 15/700 + `.ic` 图标片；正文 14–15/1.6–1.7；数字 mono + `tabular-nums`；说明 11–13 `--sub`。
- **视图结构**：`<section class="view">` → 要么 `.wrap`/`.col` 网格排 `.card`，要么 `.kb-layout` 两栏读器。入场用 `fadeIn` 错峰。
- **无障碍/动效**：聚焦有 `:focus-visible` 环；尊重 `prefers-reduced-motion`（大动效要能降级）。

### 6.0 效果图门禁（先看长什么样，再写代码）

**缘起**：08-26 一天换了四套视觉语言（粉 Ins → 冷硬科技 v6 → 钢蓝浅色 → v7 糖果），每次都是「一句话描述风格 → 整份 CSS 重生成 → 走查 → 不满意 → 再来」；`styles.css` 全史 21 次提交 +1987/−888。**从没有一张效果图被否掉，因为从没出过效果图。** 改一页效果图几分钟，改整份 CSS 再走查几小时——把迭代挪到最便宜的阶段。

**何时触发（只有三种，其余不触发）**：
1. **新视觉语言**：换主色 / 圆角体系 / 阴影风格 / 字体——任何会改 §1 那句话的事；
2. **新组件类**：§3 表里没有的组件（给 `.card` 加个 modifier 不算）；
3. **新布局骨架**：既不是 `.wrap` / `.col` 网格、也不是 `.kb-layout` 两栏读器的页面结构。

沿用现成类的增删改、文案、数据接线、修 bug——**不触发**，直接走 §6.1。

**流程**：
1. 用内置 `artifact-design` skill 出**一页 HTML 效果图**：只用 §2 的令牌与 §3 的现成类（新组件类在效果图里先定名、先写样式），明暗各一态，真文案不 lorem；
2. 存 `docs/reference/devhtml/效果图-<视图或组件>-vX.html`（沿 devhtml 惯例；HTML 自渲染，不存 PNG）；要给人看链接就发成 Artifact；
3. **人过目定稿**——不满意改效果图，不碰 `styles.css`；
4. 定稿后才进实现：把效果图里的新类**原样**搬进 `styles.css`（就近镜像同类规则），再走 §6.1 六步；
5. 效果图**不替代走查**：它只锁「长什么样」，行为 / 状态 / console 报错仍靠 §6.1 第 6 步。
