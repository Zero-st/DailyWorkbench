# 今日「温故」卡 · 蒸馏复用抓手 · 设计

> 版本：v1.0　制定：2026-08-31
> 定位：让**蒸馏飞轮真正闭合**的最小切片——旧蒸馏卡每天在「今日」自己浮现，把"存了不用"变成"会回头用"。
> 缘起：`/brainstorming` 定论——主心骨=个人知识飞轮；首个要跑通的闭环=蒸馏；先攻**复用端**（"整条飞轮没跑通"，捕获侧已通，缺"一周后真的复用到"）。
> 关联：[`产品-IA评审.md`](产品-IA评审.md)、[`知识飞轮-路线图.md`](../planning/知识飞轮-路线图.md)、[`界面设计准则.md`](界面设计准则.md)。

---

## 1 · 目标与非目标

**目标**：蒸馏库里已有的经验卡，能在「今日」被动地"回来找你"，让你真的回看→复用。这是飞轮转起来的第一个可见证据。

**非目标（YAGNI 死守）**：
- 不做"相关时浮现"（按当前主题匹配）——留待以后。
- 不做复盘周聚合。
- 不改蒸馏的捕获流程（已通）。
- 复用状态**不**写回卡片 frontmatter（先 localStorage，证明有用再迁）。
- 不碰后端、不动数据契约、不加依赖。

---

## 2 · 用户故事

打开工作台停在「今日」→ 顶部看到 `🔁 该复用了 · N`，列 1–3 张旧蒸馏卡（标题 + 平台徽标 + 主题 + "X 天没看"）→ 点【打开】跳蒸馏库读全文；点【👍有用】这张下次更晚再来；点【✓已内化】归档不再推。第二天换一批到期的卡。

---

## 3 · 挑卡算法（简化间隔重复 / Leitner-lite）

每张卡在 localStorage 存 `{ box, lastReviewed, archived }`：
- **新卡**（无记录）＝立即到期，`box=0`。
- **到期判定**：`today >= lastReviewed + INTERVAL[box]`，`INTERVAL = [0, 2, 7, 16, 35]` 天（box 超过末尾按末值）。
- **候选**＝未归档 且 到期的卡；按"超期天数"降序，取前 **3**。
- **反馈**：
  - 👍有用 → `box = min(box+1, 4)`、`lastReviewed = today`（下次更晚再来）。
  - ✓已内化 → `archived = true`（永不再推）。
  - 打开 → 记 `lastReviewed = today`、`box` 不变（看过了，但没说会不会）。
- 无到期卡 → 整块静默不显示（不占地方、不制造焦虑）。

## 4 · 数据流与复用

```
今日渲染 → renderRecall()
  ├─ fetch GET /api/kb/deposits?module=蒸馏库   （已有端点，列卡）
  ├─ 读 localStorage["wb_recall"] = { [vaultPath]: {box,lastReviewed,archived} }
  ├─ 交叉挑到期卡（前 3）
  └─ 渲染进 #recallBlock；按钮回写 localStorage 后就地重渲染
打开 → window.switchView('distill') + window.distillOpen(vaultPath)   （复用现成）
```

**复用现成的**：`GET /api/kb/deposits`（后端已有）、`window.distillOpen`/`window.switchView`、`icon()`（`js/core/icons.js`）、`.distill-card`/`.chip` 样式与 token。**新增仅前端一个薄模块。**

---

## 5 · 组件与边界

- **新增** `js/features/recall.js`：`export function renderRecall()`；内部函数 `_due()`（挑卡）、`_state()`/`_save()`（localStorage）、`_draw()`；window 桥 `recallOpen/recallUseful/recallArchive`（内联 onclick 用，遵"文件末尾挂处理器"约定）。
- **挂载点**：`index.html` `#view-home` 顶部新增 `<div id="recallBlock"></div>`（在 `.grid` 之前）。
- **触发**：`js/app.js` `render()` 里调 `renderRecall()`（与 `renderTodayReview` 并列，每次渲染都刷）。
- **降级**：`/api/kb/deposits` 失败/无后端（手机/离线）→ 静默隐藏，绝不影响今日其它内容（try/catch + 空则不渲染）。
- **边界清晰**：只读 deposits + 只写自己的 localStorage key；不依赖 data.json；卡已从库删则不在 deposits 里、自然不显示（残留 state 忽略）。

---

## 6 · 视觉（遵界面设计准则）

- 复用 `.card` 外壳 + `.ic-svg` 图标；卡片行仿 `.distill-card`；按钮用 `.button.sm` / `.button.sm.ghost`；徽标用 `icon()` 平台图标。
- 标题行 `🔁 该复用了 · N`（🔁 用内联 SVG，不用 emoji）。
- 明暗两主题均走 token，无硬编码色。
