## 1 · 结论 + 分层评分

**一句话**：知识飞轮**最窄闭环真实可用**——捕获→蒸馏(六维卡)→入库(Obsidian 251 篇)→复用(温故卡)全链路走查通过，后端韧性好。**但表现层拖后腿**：大面积 emoji 图标在无 emoji 字体环境 tofu、移动端底部导航错乱、主题"跟随系统"有 bug、若干死控件/下架代码漂移。产品骨架已立，**该补的是"皮"和边角，而非核心逻辑**。

| 层 | 评分 | 一句话 |
|---|---|---|
| 产品功能 | **4 / 5** | 闭环通、价值清晰；缺"捕获→卡一步化""相关时浮现" |
| UI 视觉 | **2.5 / 5** | emoji tofu 大面积拉低观感；深色模式覆盖不全 |
| 交互体验 | **3 / 5** | 桌面顺手；移动端导航基本不可用 + 死快捷键 + 主题 bug |
| 技术健壮性 | **3.5 / 5** | 后端不可达/401/429 有友好文案、空态友好、写入稳；但下架代码仍加载并报 404 |

## 3 · 分层优化建议（每条带 优先级 · 代价·门性）

### 产品功能
| # | 建议 | 优先级 | 代价·门 |
|---|---|---|---|
| P1 | **资讯条目直连捕获/蒸馏**：资讯卡现只有"存进知识库"，无"→收件箱/→蒸馏"。让输入端一步进飞轮，减少手动搬运 | 中 | 低·双向 |
| P2 | **复用端"相关时浮现"**：温故卡现只按时间（"0天没看"），加按 topic/tag 匹配当前上下文浮现（CHANGELOG 已列候选） | 中 | 中·双向 |
| P3 | **捕获→卡"一步化"评估**：后端直跑蒸馏（链接→卡）。**注意**：违背"零依赖·人在环中"取舍，属较大门，别过早自动化，真高频再评估（对照 `design-principles`） | 低 | 中·较大门 |

### UI 视觉
| # | 建议 | 优先级 | 代价·门 |
|---|---|---|---|
| **U1** | **消灭 emoji 图标 tofu**（本次最大观感问题）：全站 447 处 emoji，图片型（📄×251/📁×81 知识库树、➕/📥/💾/🎬/💡/🧹/🧠/🌋/🚨…）在无 emoji 字体环境（本 Linux/Chromium、许多服务器/浏览器）**全部 tofu □**——知识库树 251 文件+81 目录满屏 □，观感"坏掉"。侧边栏已用内联 SVG 渲染正常 → **不一致**。**改**：按 `界面设计准则.md`（emoji→内联 SVG）把 kb 树/按钮/平台片的 emoji 换成 `js/core/icons.js` 的 SVG（或至少给 `font-family` 兜个 emoji 字体栈） | **高** | 中·双向 |
| U2 | **深色模式覆盖侧边栏**：dark 时主区变深、左侧 `.side-nav` 仍白（其背景透明、未定义深色变量）。补深色 token | 中 | 低·双向 |
| U3 | **全局 footer 收敛**：`本机数据…/功能自检/导出/备份/恢复 + 社区 credit` 现出现在**每个视图**底部，噪音且含 tofu。建议只留今日或折叠 | 低 | 低·双向 |
| U4 | 单卡时 distill/models 右侧/下方大片留白——空态可更充实（引导/近期动态） | 低 | 低·双向 |

## 4 · 复盘

**做对了什么**
- 先跑通最窄闭环再谈优化——走查证明捕获→蒸馏→入库→复用**真实可用**，不是 demo。
- 后端韧性到位：不可达/鉴权/限流都有引导，空态普遍友好，不白屏。
- 安全意识：API Key UI 脱敏、密钥只在本机后端。

**暴露的问题（按影响排序）**
1. 表现层与"设计准则"脱节：emoji tofu 大面积（U1）、移动端导航坏（X1）——这两条最伤第一印象。
2. 主题系统不自洽（X2 深色不清 / U2 侧栏不深）。
3. 下架不彻底 → 死快捷键(X3)、死控件(X4)、404(T1)、孤儿视图(T3) 一堆漂移。

**下一步 backlog（可执行、排序）**
1. **U1 emoji→SVG** + **X1 移动端导航** ——一次"表现层修复"批次，收益最大、都是双向门。
2. **X3+T1+X4** ——"下架收尾"批次：删死快捷键/死控件、止血 404、修 README §二 误述。
3. **X2+U2** ——"主题自洽"批次。
4. **X5/X6/T2** ——小 copy/刷新/守卫修复，随手带。
5. 产品向（P1/P2）排在表现层修完之后；P3/T3 属较大门，真触到再评估。

> 本评审只走查+记录，**未改任何业务代码**；上述均为建议 backlog，实施另起任务、逐批征询。
