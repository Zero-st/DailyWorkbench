## 1 · 问题与目标

刷小红书/B站/微博/即刻看到好帖子、冒出好想法，**没有低摩擦落点**，看完就丢。

工作台已有捕获层雏形「收件箱」（`js/features/inbox.js`，秒存链接+一句话想法，纯 localStorage），但它要求**离开帖子、切到工作台、手动粘链接**——摩擦仍在，且"当时为什么觉得好"这个最易蒸发的信息没被接住。

**目标**：读帖当场，选中那段精华 → 写下感悟 → 一次点击落进收件箱，之后一键升级成六维经验卡。

**核心洞察（对整条飞轮的最大加成）**：小红书/微博反爬 + 需登录 + JS 渲染，后端 `urllib` 抓不到正文——这是路线图把抓取留给外部 skill 的原因。但**用户选中的那段就是精华**。「选中摘录」＝人工取材，**直接绕过反爬**，让蒸馏不再依赖抓页面。

## 2 · 架构

```
帖子页 content script ─选中→浮按钮/右键─▶ 页内面板(shadow DOM，写感悟/标签)
        └─ sendMessage ─▶ background SW ─ fetch POST ─▶ 后端 /api/inbox/* ─▶ inbox.local.json（PC 真源）
                                                                                   ▲
工作台 收件箱视图 inbox.js ◀── GET /api/inbox ───────────────────────────────────────┘
        └─ localStorage wb_inbox 降为「离线队列/缓存」：后端不可达时暂存，恢复后自动 flush
```

三条原则把长期维护面压到最小：

1. **扩展零站点解析**。只取 `location.href`、`document.title`、`og:title/og:description`、`getSelection()`。**不写任何小红书/B站的 DOM 选择器**——那是最容易随站点改版而坏的东西。平台识别留在工作台已有的 `detectPlatform(url)`（`js/core/platforms.js`），Python 侧**不复制**域名表。
2. **持久化放仓根 `inbox.local.json`**（gitignore，与 `workbench.local.json` 同族；可由其 `inbox.path` 覆盖）。**不放 vault**：收件箱是暂存工作集、不是知识；且沉淀根当前 = `devmd` 库根，个人感悟不应无条件进去。
3. **工作台改「API 优先 + 离线队列」**，保住北极星"离线可跑"：断后端仍能秒存（写 localStorage 并标 `pending`），联上后自动补推。

## 3 · 数据模型

扩展与工作台共用一个条目形状（比现版多 `title/excerpt/source/updatedAt`）：

```js
{ id, type:'clip'|'idea', url, title, excerpt, note, tags:[], platform,
  status:'待处理'|'已蒸馏'|'已归档', source:'ext'|'web', at, updatedAt }
```

- `excerpt`＝选中摘录（截 5000 字），`note`＝**你的感悟**。二者**成对**存放，是 Readwise 式 highlight+annotation，也是"人工取材绕过反爬"的载体。
- `type`：有链接＝`clip`（剪藏），纯想法＝`idea`（灵感）。
- `source`：`ext`（扩展）/ `web`（工作台内），列表里出角标，便于观察哪条路真被用。

## 4 · 后端 API

新增 `backend/clients/inbox.py`（纯标准库 JSON 读写；tmp + `os.replace` 原子写；文件损坏则备份 `.bak` 后空启动，不崩）。路由沿用 GET/POST 两式，**不引 PATCH/DELETE 动词**（`server.py` 只有两张路由表）：

| 路由 | 作用 |
|---|---|
| `GET /api/inbox` | 列表（新→旧） |
| `GET /api/inbox/ping` | 扩展弹窗显示「已连上工作台 · N 条」 |
| `POST /api/inbox/add` | 服务端补 `id/at/status`；同 `url`+`excerpt` 60s 内去重 |
| `POST /api/inbox/update` | `{id, patch:{status\|note\|tags}}` |
| `POST /api/inbox/delete` | `{id}` |

### 4.1 Origin 允许列表（必要加固）

现后端对 JSON 响应统一放 `Access-Control-Allow-Origin: *`（`server.py:133`）。若不校验来源，**任意网页**都能用 `text/plain` 简单请求（无预检）写本地 API。故 `/api/inbox/*` 的 POST 校验 `Origin`：

- 放行：**无 Origin**（curl / 本地脚本）、`http://127.0.0.1:*` 与 `http://localhost:*`（工作台自身）、`chrome-extension://*`（扩展）
- 其余 → `403`

扩展走 background `fetch` + `host_permissions`，工作台同源，**都不触发 CORS 预检**，故不需要 `OPTIONS` 分支。
> `/api/kb/save` 存在同类暴露，可顺手同样加固（可选项，不阻塞本设计）。

## 5 · 扩展（MV3，`extension/` 入仓，开发者模式 load unpacked）

文件：`manifest.json` · `background.js`（右键菜单 + 转发 fetch）· `content.js`（浮按钮 + 页内面板）· `popup.html/.js` · `icons/`。

**三个入口，共用一个面板：**

1. **选中即现**：四站（`*.xiaohongshu.com` / `*.bilibili.com` / `*.weibo.com` / `*.okjike.com`）选中文字后，选区旁浮出「存到工作台」小按钮。
2. **右键菜单**「存到工作台收件箱」：**全站可用**（contexts = selection/page/link）。非四站页面靠 `activeTab` + `scripting.executeScript` 临时注入面板——知乎/公众号等任意文章页也能存，**不必预先列域名**。
3. **工具栏 popup**：无选区时快速存（链接+标题+感悟）；设置（后端端口默认 8899、浮按钮开关、浮按钮生效域名）；连接状态（`/api/inbox/ping`）；「打开工作台收件箱」。

**页内面板**用 shadow DOM 隔离站点样式：标题/链接只读 → 摘录 textarea（预填选区、可改）→ **感悟 textarea 自动聚焦** → 标签 → `保存 ⏎` / `取消 Esc`。成功「✓ 已存到工作台」1.2s 自动收起；失败「工作台后端未启动（127.0.0.1:8899）」+ 重试。

**不做（YAGNI，可后补）**：站点专属抓作者/正文、自动全文抓取、键盘快捷键、角标计数。

## 6 · 工作台侧改动

- `js/features/inbox.js` 抽数据层 `store`：`list()` 先 GET API、失败回 localStorage；`add/update/remove()` 先 POST、失败写本地标 `pending`，下次 `list()` 成功后自动 flush。渲染层加标题 + 摘录引用块 + 感悟 + 标签 + `ext/web` 来源角标。
- **`→蒸馏` 内嵌摘录**：`js/views/distill.js` 的 `_distillCmd(plat, url, extra)` 若带 `excerpt`，指令改为「以下是我从该帖选中的摘录与感悟，**直接据此**提炼六维经验卡，无需再抓取页面」；`distillNew(prefill)` 同时把摘录预填进正文区。这是第 1 节洞察的落地。
- **拖拽即存**：捕获卡 `ondrop` 读 `text/uri-list` / `text/plain`，双窗口并排时零点击。

## 7 · 边界与错误处理

| 场景 | 行为 |
|---|---|
| 后端未启动 | 扩展明确提示 + 重试；工作台走离线队列 |
| 重复保存 | 同 `url`+`excerpt` 60s 内去重 |
| 超长选区 | `excerpt` 截 5000 字 |
| 并发写 | 全局锁包住「读-改-写」+ tmp 名带 pid/线程 id。**服务器是 ThreadingHTTPServer，且前端补推/扩展连点会并行提交**——无锁时实测 25 条并发提交 0 条存活并写坏 JSON（走查 2026-09-03 发现，见 CHANGELOG v0.10.0 Fixed） |
| JSON 损坏 | 备份 `.bak` 后空启动，不崩 |
| 恶意网页写本地 API | Origin 允许列表 → 403 |
| 网络暴露 | 后端仍只绑 `127.0.0.1` |

## 8 · 验证

1. 后端：curl 五路由；非法 Origin 得 403。
2. 工作台：断后端秒存进离线队列 → 起后端刷新自动 flush。
3. 扩展 load unpacked：小红书详情页选中 → 浮按钮 → 写感悟 → 保存 → 工作台收件箱出现带摘录的卡。
4. `→蒸馏`：指令与正文区已内嵌摘录+感悟，且提示"无需再抓取页面"。
5. 右键菜单在知乎等非四站页面同样可存。
6. 后端停掉时扩展提示文案正确。

## 9 · 不做什么（YAGNI 边界）

- **不上云、不做多端同步**（路线图 Phase 3，单向门需先写 ADR；当前"电脑为主"未触发）。
- **不引入重型抓取**（playwright/爬虫）——碰"零依赖"北极星；人工取材已解决正文问题。
- **不动 favs**：`favs` 保持"资讯页 ☆ 稍后读"原职（被动收藏资讯条目）；`inbox` 是主动捕获待蒸馏，二者分工不合并。
