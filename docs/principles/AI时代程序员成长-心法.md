# AI 时代程序员成长 · 心法

> 性质：**活文档 · 心法**。与 [`开发心法-多维思维总纲`](开发心法-多维思维总纲.md) 同层：那篇讲「一个功能从想法到复盘，**何时该戴哪顶帽子**」，本文讲「**AI 替你写代码之后，人该长哪些肌肉、怎么练**」。
> 定位：回答一个反复冒出来的问题——「AI coding 时代，程序员怎么提升能力和思维」。不讲鸡汤，只拿本仓的真实证据说话。
> 关联：[`../TECH_CHARTER.md`](../TECH_CHARTER.md)（维度四「人机协作流程」是本文的操作红线）、[`../adr/`](../adr/)（决策留证）、[`../design/工作台走查评审-v0.8.0.md`](../design/工作台走查评审-v0.8.0.md)（验证肌肉的实例）、[`../research/工具链-MCP与Skill地图.md`](../research/工具链-MCP与Skill地图.md)（可复用资产清单）。

## 0 · 为什么要这份（先看一个事实）

本仓从 2026-08-26 到 09-02，**8 天 62 个 commit**，一个人加 Claude。`js/`、`backend/` 里的代码，大半是 AI 写的。

反问一句：**这 8 天里，哪些东西是人不可替代的产出？** 翻一遍仓库，答案几乎全在 `docs/`，不在 `js/`：

- [`TECH_CHARTER`](../TECH_CHARTER.md) 的北极星「零构建·零依赖·离线」和「要不要引入 X」四问——**是人在说不**。
- [`adr/0001–0005`](../adr/)——五扇单向门，每扇都是人拍板、人担后果。
- [`开发心法`](开发心法-多维思维总纲.md) 的产品帽判据——「这周我会用几次」这种问题，AI 答不了，只有你能对自己诚实。
- `.claude/plan/anti-rot-governance.md` 的缘起：「随着代码增加会不会变成垃圾堆」——**这个问题是人提的**。AI 能答，但不会自己在某个周二早上停下来问。

代码是 AI 的，**判断、约束、验证、留证是人的**。而让项目 8 天没腐烂的，恰恰是后者。

**所以本文的核心命题一句话：AI 时代程序员的复利不再是代码行数，而是沉淀下来的判断力、约束和验证能力。** 下面全是这句话的展开。

## 1 · 重新定价：什么贬值、什么升值

| 贬值（AI 做得又快又好） | 升值（AI 做不了或做不稳） | 本仓证据 |
|---|---|---|
| 语法 / API 记忆 | **问题定义**：把模糊想法说成可验证的规格 | `.claude/skills/speckit-*` 整套；每份 plan 都有「验证」节 |
| 样板代码、脚手架 | **约束设计**：北极星、红线、敢说不 | 宪章四问；ADR 0002 拒 React/Vue、0003 拒全量 TS |
| 「把清晰需求翻成代码」的速度 | **验证能力**：我怎么知道它真的对 | CI 真门禁（禁 `\|\| true`）、chrome-devtools 走查、console 零 error |
| 单一框架的熟练度 | **原理级知识**：拿来评审 AI 给的方案 | `design-principles` skill：把现场对到 DDD/DDIA/PoEAA 的行动卡 |
| 单点技能深度 | **决策与留证**：可逆性判断、单向门写 ADR | 双向门直接试，单向门才写 ADR |
| — | **品味**：什么是「好」，什么是「坏掉了」 | emoji 豆腐块 → SVG（走查 U1）；功能全对但第一眼像坏的，人才看得出 |
| — | **跨层宽度**：能和 AI 在任何一层对话 | 一人打通前端 / Python 后端 / Supabase / CI / PWA |

**读法**：左列是 AI 的护城河，别在这上面跟它比；右列是你的护城河，AI 越强，这列越贵。

## 2 · 四个杠杆：从「写代码的人」到「让正确的代码被写出来的人」

| 杠杆 | 一句话 | 本仓载体 | 怎么练 |
|---|---|---|---|
| **规格 Specify** | 写不出完成判据 = 自己还没想清楚 | plan 先行（宪章维度四）、speckit 流程 | 每个丢给 AI 的任务，先写一句「怎么算做完」。写不出来就别开工 |
| **约束 Constrain** | AI 什么都能做，人的价值是划边界 | 北极星、四问、`CLAUDE.md`、单向门清单 | 每次「要不要引入 X」走一遍四问；每个不可逆决定留 3 行 ADR |
| **验证 Verify** | 不会验证的东西，不要让 AI 造 | `ci.yml` 真门禁、`bump_version.py --check`、走查明暗两主题 | 验证先于生成：先想好红灯长什么样，再让 AI 让它变绿 |
| **判断 Judge** | 可逆性 + 维护税 + 删除测试 | 双向门/单向门、心法 §4 三关四档 | 每周复盘一条：这轮哪条判断值得进宪章 / ADR / skill |

四个杠杆里，**判断是 AI 最弱、人最不可替代的**。因为判断需要两样 AI 没有的东西：对自己的诚实，和对后果的责任。

## 3 · 五个思维转变（具体到操作）

1. **「我怎么实现」→「我怎么知道它对」。** 实现交给 AI，验证留给自己。宪章里「禁 `|| true` 假绿」那条，本质就是这个转变——宁可诚实删掉一个测试，也不留看着在测其实没测的绿灯。
2. **「学工具」→「学原理」。** 框架、库、API 会被 AI 抹平；DDD、DDIA、PoEAA、《重构》这类原理级知识不会，因为你要拿它们**评审 AI 的方案**。`design-principles` skill 就是这个用法：不替你实现，只告诉你「该考虑什么、代价是什么、出处在哪」。
3. **「做完」→「留证」。** AI 写的代码没有「为什么」，为什么只存在你脑子里，不写下来三个月后连你也不知道。所以有 ADR、宪章末尾的「反例存档」（2139 行单 IIFE、硬编码 `E:\`、假 CI）、心法的「缺了它长的疮」。**留证是给未来的自己和 AI 都能读的上下文。**
4. **「一次性对话」→「可复用资产」。** 每次和 AI 的好配合，都该问一句「这能不能变成 skill / memory / prompt」。本仓有 `doc-filing`（文档归位）、全局有 `harvest-prompts`（收尾提炼提问）、`loop-engineering`（有界循环）——这些才是 AI 时代真正在累积的杠杆，代码不是。
5. **「独行侠」→「带一个知识面无限宽、但没有责任感的搭档」。** 管理者思维：委派清楚（规格）、审查到位（验证）、划好边界（约束）、不 micromanage 也不放任。宪章维度四「命令前中文说明副作用」「commit 只在明确要求时做」——就是给这个搭档定的规矩。

## 4 · AI 放大的五个坑 + 护栏

[`开发心法`](开发心法-多维思维总纲.md) §5 已列过一人项目的三个坑。AI 不制造新坑，但**把旧坑挖深**：

| 坑 | 为什么被 AI 放大 | 本仓证据 | 护栏 |
|---|---|---|---|
| **产品帽更被挤掉** | 造得越快，越容易造没人用的东西 | `cap/ov/sess/schedule` 四个视图 + 整个 `mobile/`、`twa/`，一次 commit（c7b14ad）整批删，一点不心疼 | 心法 §4 三关（频率门/飞轮门/人在环中门）——AI 时代**必须先过门再开工**，因为开工太便宜了 |
| **理解债** | 没读懂也能跑；出事时修不了 | 856df28：渲染逻辑耦合到已删的 `.tab` 按钮 → 资讯页白屏 | 「一文件一句话说清」；**读不懂的不合并**；render 层禁读 DOM 判路由 |
| **技能萎缩** | 判断力来自实践；从不亲手判断，判断力会退化 | （预防性）本仓尚无事故，但趋势是所有代码经 AI 手 | 每周一次无 AI 手写核心逻辑；把 review AI 输出当刻意练习，而不是扫一眼 |
| **验证幻觉** | 「测试通过了」≠ 通过了 | 宪章回溯表：假 CI `\|\| true` 恒绿 | 真门禁；**亲眼看它先红再绿**；走查 console 零 error 才算 |
| **重构爽感放大** | AI 让重构近乎免费 → 更容易借「打磨」逃避方向决策 | 心法 §5 自检信号：连续几周动作全是表现层/工程层 | 动手前写一句「这次解决谁的什么问题」——写不出就是在逃避 |

**规律**：五个坑的护栏没有一条是「更努力」，全是**流程和门禁**。护栏 > 自律，AI 时代尤其如此。

## 5 · 练习节律（按频率分层，可量化）

| 频率 | 动作 | 对应杠杆 |
|---|---|---|
| **每个任务** | 一句完成判据 + 这次戴哪顶帽子 | 规格 / 判断 |
| **每个 AI 产出** | 读懂再合并；问一句「它为什么这么做」；找一处能删的 | 验证 / 判断 |
| **每周** | 一次无 AI 手写核心逻辑（半小时够）；一条经验进宪章 / ADR / skill | 抗萎缩 / 留证 |
| **每月** | 原理书一章（DDD / DDIA / 重构任一），在本仓找一处对照应用 | 原理 |
| **长期** | 横向跨一层：前端人补后端 / 数据 / 运维。AI 把跨层沟通成本打下来了，**宽度成了杠杆** | 宽度 |

**铁律：练的是判断，不是产出。** 每周手写那半小时，目的不是写出更好的代码，是保住「一眼看出 AI 写歪了」的能力。
