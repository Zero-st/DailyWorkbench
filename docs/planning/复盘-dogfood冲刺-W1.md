## 0 · 规则（写死，防工程帽偷跑）

1. 唯一允许的代码改动：**阻断闭环的 bug**——定义是「某一步无法完成」，不是「不顺手」。不顺手的记下来，周末再说。
2. 每天至少走一次真实闭环：刷到内容 → 收件箱秒存 → （至少隔天）蒸馏成六维卡 → 看「今日温故」卡是否浮现、是否真点开。
3. 摩擦写**具体动作**（例：「复制蒸馏指令到 skill 再粘回，来回切了 3 次窗口」），不写「不顺手」「有点烦」。
4. 每天结束前在 Obsidian 库目录 `git add -A && git commit -m "backup YYYY-MM-DD"`（第 1 档手动备份，权威副本这周开始装真东西）。

## 4 · 预置映射（摩擦 → 候选功能，周末对号）

- 「复制指令 → 人跑 skill → 粘回」占主导 → 重新评估 P3「捕获→卡一步化」。**较大门**（撞「人在环中」取舍），先写 ADR 再动，不直接做。
- 「卡存了没回头看 / 温故卡浮现的不相关」→ P2「相关时浮现」（心法 §4 已论证过三门），第 3 档最小版：按 topic/tag **精确**匹配，不做语义相似度。
- 「有灵感没地方记」→ 路线图 Phase 2 灵感留存（速记 → Obsidian `灵感/日期/`）。
- 「怕丢」→ vault git 备份从手动升到脚本（路线图 Phase 2 后半）。
- 别的 → 写进摩擦清单，走三门。
