## 1 · ✅ 已完成（可用）

### 1.1 前端 PWA · 6 个功能视图（v0.8.0 MVP 聚焦后，按知识飞轮排列）

分组：**今日** ｜ **飞轮**(资讯·知识库·蒸馏库·AI助手) ｜ **设置**(模型管理)。MVP 只留飞轮主轴 + AI 配置。

| 分组 | 视图 | 说明 |
|---|---|---|
| 今日 | `home` | 捕获+复盘中枢：代办 + 复盘 + 温故卡 + 速记/收藏/常用入口/快捷启动（原仪表盘交互件已并入） |
| 飞轮·输入 | 资讯 `info` | AI 日报 + 每日新闻（分栏） |
| 飞轮·沉淀 | 知识库 `kb` | Obsidian vault 浏览 / 检索 / 双链 / 沉淀 + 新建笔记/蒸馏/搜索动作 |
| 飞轮·蒸馏 | 蒸馏库 `distill` | up 主经验卡：链接→六维萃取→落 Obsidian `蒸馏库/` |
| 飞轮·输出 | AI 助手 `ai` | 大白话问答，可「存知识库」对话精华 |
| 设置 | 模型管理 `models` | AI 平台与模型配置（Supabase 云端 / localStorage 兜底） |

> **MVP 从导航下架（代码/数据全保留，加回按钮即恢复）**：能力速达 `cap`、动态 `sess`、系统状态 `ov`——三者均属「看机器」遥测/工具，不推动飞轮流动。
> 更早已下线：仪表盘（拆解分发·v0.7.0）、Skill 统计（→cap·v0.7.0）、本周动态（→sess·v0.7.0）、课程表（离题·v0.7.0）——代码同样保留。

**通用体验**：深色/浅色主题、桌面自适应（宽窗双栏/窄窗单列）、离线可开（Service Worker）、离线提示条、防白屏（`normalizeData` 兜底 + `render` try/catch）。
